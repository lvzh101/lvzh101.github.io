五、常微分方程

1. 可分离变量微分方程

$$\frac{\mathrm{d}y}{\mathrm{d}x} = f(x)g(y) \implies \int \frac{\mathrm{d}y}{g(y)} = \int f(x),\mathrm{d}x$$

说明与总结：

  • 右端能写成 $x$ 的函数与 $y$ 的函数之积时可用。
  • 分离变量后两边积分；注意由 $g(y) = 0$ 给出的常数解在分离时被两边除掉，可能丢解，需单独检验。

2. 齐次微分方程

$$\frac{\mathrm{d}y}{\mathrm{d}x} = \varphi\left(\frac{y}{x}\right)$$

令 $u = \frac{y}{x}, y = ux, \frac{\mathrm{d}y}{\mathrm{d}x} = u + x\frac{\mathrm{d}u}{\mathrm{d}x}$：

$$\implies \frac{\mathrm{d}u}{\varphi(u) - u} = \frac{\mathrm{d}x}{x}$$

说明与总结：

  • 右端可化为 $y/x$ 的函数时为齐次方程。
  • 换元 $u = y/x$ 后化为可分离变量方程，积分后回代 $u = y/x$；另需检验 $\varphi(u) - u = 0$ 对应的特解 $y = ux$（直线解）。

3. 一阶线性微分方程（通解公式）

$$\frac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)$$

$$y = e^{-\int P(x),\mathrm{d}x} \left( \int Q(x) e^{\int P(x),\mathrm{d}x},\mathrm{d}x + C \right)$$

说明与总结：

  • 须先化为标准形式（$y’$ 系数为 1）再套通解公式；$Q(x) \equiv 0$ 为齐次，$Q(x) \not\equiv 0$ 为非齐次。
  • 最易错点：外层 $e^{-\int P,\mathrm{d}x}$ 与积分内 $e^{+\int P,\mathrm{d}x}$ 指数符号必须相反；$\int P,\mathrm{d}x$ 取同一不含常数 $C$ 的原函数即可，切勿在指数里再额外 $+ C$（否则重复引入常数翻车）。

4. 伯努利方程（数一）

$$\frac{\mathrm{d}y}{\mathrm{d}x} + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$$

令 $z = y^{1-n}$：

$$\implies \frac{\mathrm{d}z}{\mathrm{d}x} + (1-n)P(x)z = (1-n)Q(x)$$

说明与总结：

  • （数一专属，数二、数三不考）
  • 通过换元 $z = y^{1-n}$ 化为关于 $z$ 的一阶线性方程再求解；$n = 0$ 时本身即线性、$n = 1$ 时即可分离变量。

5. 可化为可分离/齐次的换元型方程

  • 类型一：$y’ = f(ax + by + c)$

  • 令 $u = ax + by + c, u’ = a + by’ \implies \frac{u’ - a}{b} = f(u)$

  • 类型二：$\frac{\mathrm{d}y}{\mathrm{d}x} = f\left(\frac{a_1 x + b_1 y + c_1}{a x + b y + c}\right)$

  • 平移 $x = X + h, y = Y + k$ 消去常数项化为齐次

说明与总结：

  • 两类常见换元：
  1. $y’ = f(ax + by + c)$ 令 $u = ax + by + c$ 直接化为可分离变量；
  2. 分式型先解联立方程组求平移量 $(h, k)$，无解（系数成比例）时改令 $u = ax + by$。数三小题常见。

6. 可降阶高阶方程 $y^{(n)} = f(x)$

$$y^{(n)} = f(x) \implies \text{逐次积分 } n \text{ 次，得含 } n \text{ 个任意常数的通解}$$

说明与总结：

  • 右端只含 $x$，直接连续积分 $n$ 次即可，每次积分产生一个任意常数。

7. 可降阶方程 $y’’ = f(x, y’)$（不显含 $y$）

令 $p = y’, y’’ = \frac{\mathrm{d}p}{\mathrm{d}x}$：

$$\implies \frac{\mathrm{d}p}{\mathrm{d}x} = f(x, p)$$

说明与总结：

  • 方程不显含未知函数 $y$。
  • 令 $p = y’$ 降为关于 $p$ 的一阶方程，解出 $p = \varphi(x, C_1)$ 后再对 $x$ 积分得 $y$。

8. 可降阶方程 $y’’ = f(y, y’)$（不显含 $x$）

令 $p = y’, y’’ = p \frac{\mathrm{d}p}{\mathrm{d}y}$：

$$\implies p \frac{\mathrm{d}p}{\mathrm{d}y} = f(y, p)$$

说明与总结：

  • 方程不显含自变量 $x$。
  • 令 $p = y’$ 并视 $p$ 为 $y$ 的函数，用 $y’’ = p \frac{\mathrm{d}p}{\mathrm{d}y}$ 降为关于 $p, y$ 的一阶方程；解出 $p = \varphi(y, C_1)$ 后再分离变量求 $y$。

9. 线性微分方程解的结构

  • 齐次 $y’’ + py’ + qy = 0$：

$$y = C_1 y_1 + C_2 y_2 \quad (y_1, y_2 \text{ 线性无关})$$

  • 非齐次 $y’’ + py’ + qy = f(x)$：

$$y = C_1 y_1 + C_2 y_2 + y^*$$

说明与总结：

  • $n$ 阶齐次线性方程的通解由 $n$ 个线性无关解线性组合；
  • 非齐次通解 $=$ 对应齐次方程通解 $+$ 非齐次方程任一特解 $y^*$。

10. 非齐次解的叠加原理

若 $y_1^, y_2^$ 分别是 $Ly = f_1, Ly = f_2$ 的特解，则 $y_1^* + y_2^*$ 是 $Ly = f_1 + f_2$ 的特解。

说明与总结：

  • $L$ 为线性微分算子。自由项可分解时分别求特解再相加。
  • 另：同一非齐次方程两个特解之差是对应齐次方程的解。

11. 由特解构造非齐次通解（常考型）

设 $y_1, y_2, y_3$ 是同一二阶非齐次线性方程的特解，且 $y_1 - y_2, y_1 - y_3$ 线性无关：

$$\implies y = C_1(y_1 - y_2) + C_2(y_1 - y_3) + y_1$$

说明与总结：

  • $y_i - y_j$ 均为对应齐次方程的解；取两个线性无关的差作为齐次通解基，再加任一特解（此处取 $y_1$）即得非齐次通解。
  • 线性无关的判据：两差之比 $\frac{y_1 - y_3}{y_1 - y_2}$ 不恒为常数。已知若干特解反求通解是高频小题。

12. 二阶常系数齐次线性方程通解

特征方程：$r^2 + pr + q = 0$

$$\begin{cases} \Delta = p^2 - 4q > 0, r_1 \neq r_2 ,(\text{实}): & y = C_1 e^{r_1 x} + C_2 e^{r_2 x} \ \Delta = 0, r_1 = r_2 = -\frac{p}{2}: & y = (C_1 + C_2 x)e^{rx} \ \Delta < 0, r = \alpha \pm \beta i: & y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x) \end{cases}$$

说明与总结：

  • 由特征方程 $r^2 + pr + q = 0$ 根的三种情形写通解。
  • 判别式速记：$\Delta = p^2 - 4q > 0$ 两相异实根、$= 0$ 二重实根 $r = -p/2$、$< 0$ 共轭复根，此时 $\alpha = -\frac{p}{2}, \beta = \frac{\sqrt{4q - p^2}}{2} ,(\beta \neq 0)$。$p, q$ 为常数。

13. 高于二阶常系数齐次方程通解（数一、数二）

特征方程：$r^n + a_1 r^{n-1} + \dots + a_n = 0$

  • $k$ 重实根 $r$：$(C_1 + C_2 x + \dots + C_k x^{k-1})e^{rx}$
  • $k$ 重复根 $\alpha \pm \beta i$：$e^{\alpha x} [(A_1 + \dots + A_k x^{k-1})\cos \beta x + (B_1 + \dots + B_k x^{k-1})\sin \beta x]$

说明与总结：

  • （数一、数二要求，数三不考：数三线性微分方程只到二阶）
  • 每个根按重数贡献对应项，各项相加即通解；共轭复根成对出现，$k$ 重复根 $\alpha \pm \beta i$ 共配 $2k$ 个任意常数。

14. 非齐次特解：$f(x) = P_m(x)e^{\lambda x}$ 型

$$y^* = x^k Q_m(x)e^{\lambda x}$$

$$k = \begin{cases} 0, & \lambda \text{ 不是特征根} \ 1, & \lambda \text{ 是单特征根} \ 2, & \lambda \text{ 是二重特征根} \end{cases}$$

说明与总结：

  • $P_m(x)$ 为已知 $m$ 次多项式，$Q_m(x)$ 为同次待定多项式。
  • $k$ 取 $\lambda$ 作为特征根的重数（二阶常系数时最多取 2）。操作流程：设好 $y^*$ 后代回原方程，对应同次幂系数比较，解出 $Q_m$ 的待定系数。
  • 特例 $\lambda = 0$（即 $f$ 为常数或纯多项式）最常考：此时 $y^* = x^k Q_m(x)$，$k$ 看 $r = 0$ 是否为特征根（$q \neq 0$ 取 0、$q = 0, p \neq 0$ 取 1、$p = q = 0$ 取 2）。

15. 非齐次特解：$f(x) = e^{\lambda x}[P_l(x)\cos \omega x + P_n(x)\sin \omega x]$ 型

$$y^* = x^k e^{\lambda x}[R_m(x)\cos \omega x + S_m(x)\sin \omega x], \quad m = \max{l, n}$$

$$k = \begin{cases} 0, & \lambda + \omega i \text{ 不是特征根} \ 1, & \lambda + \omega i \text{ 是特征根} \end{cases}$$

说明与总结：

  • $R_m, S_m$ 为 $m$ 次待定多项式（即使原式只含 $\cos$ 或只含 $\sin$，也须同时设 $\cos, \sin$ 两项）。
  • 统一以 $\lambda + \omega i$（约定 $\omega > 0$）判别：共轭根成对出现，只需判 $\lambda + \omega i$ 这一个即可，无需对 $\lambda - \omega i$ 另判；二阶时复根至多单重，故 $k$ 只取 0 或 1。设好 $y^*$ 后代回原方程比较侧系数解出待定多项式。

16. 欧拉方程（数一）

$$x^2 y’’ + p x y’ + q y = f(x) \quad (x > 0)$$

令 $x = e^t ,(t = \ln x)$：

$$x \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}t}, \quad x^2 \frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \frac{\mathrm{d}^2 y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t}$$

齐次速判特征方程：

$$r(r - 1) + pr + q = 0$$

说明与总结：

  • （数一专属，数二、数三不考）
  • 变系数方程，换元 $x = e^t$（取 $x > 0, t = \ln x$）后化为关于 $t$ 的常系数线性方程求解，再回代 $t = \ln x$。
  • 对应齐次部分可直接套特征方程 $r(r - 1) + pr + q = 0$，设 $y = x^r$ 代入即得（比换元更快）；$x < 0$ 时取 $x = -e^t$ 同理。

17. 微分方程应用建模常用关系

  • 变化率：$\frac{\mathrm{d}Q}{\mathrm{d}t} = k Q \implies Q = Q_0 e^{kt}$ （衰变 $k < 0$ / 增长 $k > 0$）
  • 牛顿冷却：$\frac{\mathrm{d}T}{\mathrm{d}t} = k(T - T_0)$
  • 混合稀释：$\frac{\mathrm{d}m}{\mathrm{d}t} = v_{\text{进}} c_{\text{进}} - v_{\text{出}} \frac{m}{V}$

说明与总结：

  • 应用题先据几何/物理意义列方程并确定初始条件，再求解。
  • 几何套路：切线斜率 $y’ = k$；曲线在点 $(x, y)$ 处切线/法线在坐标轴上的截距用 $Y - y = y’(X - x)$ （切线）、$Y - y = -\frac{1}{y’}(X - x)$ （法线）令 $X = 0$ 或 $Y = 0$ 求出后列等式。
  • 物理套路：指数增长/衰变最常见，牛顿冷却、溶液混合稀释次之。

18. 微分方程基本概念（阶与通解/特解）

  • 阶 $=$ 方程中未知函数最高阶导数的阶数
  • $n$ 阶方程通解含 $n$ 个独立任意常数；由初值条件定常数得特解

说明与总结：

  • 判断方程的阶；通解中独立任意常数个数 $=$ 方程阶数；初始条件（如 $y(x_0) = y_0, y’(x_0) = y_0’$）用于确定特解。
  • 注意“独立”：若表达式中两常数可合并为一个（如 $C_1 + C_2 = C$、$C_1 e^{C_2}$ 等），则实际独立常数个数不足，该式不构成 $n$ 阶方程的通解，易被误判，化简后再数。

19. 常用麦克劳林展开式（级数法/特解凑配速查）

  • $e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!}$
  • $\sin x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!}$
  • $\cos x = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!}$
  • $\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n \quad (\vert{}x\vert{} < 1)$
  • $\ln(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n} \quad (-1 < x \leq 1)$

说明与总结：

  • 幂级数解法及验证特解时常用这几条标准展开。
  • 微分方程章里既用于“设幂级数解 $y = \sum a_n x^n$ 代入定系数”，也用于核对 $e^{\lambda x}、\cos \omega x、\sin \omega x$ 型自由项。$e^x, \sin x, \cos x$ 收敛域为全体实数。

20. 一阶常系数线性差分方程（数三）

$$y_{x+1} + a y_x = f(x) \quad (a \neq 0)$$

  • 齐次通解：$y_x = C(-a)^x$
  • 通解 $=$ 齐次通解 $+$ 特解 $y_x^*$

说明与总结：

  • （数三专属，数一、数二不考）
  • 差分方程与微分方程并列考查，解题结构完全平行：先求齐次通解 $C(-a)^x$，再按自由项 $f(x)$ 类型用待定系数法求特解。
  • $f(x) = b$ (常数)时：$a \neq -1$ 设 $y^* = A$，$a = -1$ 设 $y^* = Ax$；
  • $f(x) = P_m(x)d^x$ 时设 $y^* = x^k Q_m(x)d^x$，$k$ 看 $d$ 是否为特征根 $-a$。
