四、多元函数微积分学

1. 二元函数的极限与连续

$$\lim_{(x, y) \to (x_0, y_0)} f(x, y) = A$$

说明与总结：

  • 极限存在要求动点 $(x, y)$ 沿任意路径趋于 $(x_0, y_0)$ 时 $f$ 都趋于同一常数 $A$。
  • 判不存在的常用手段：找两条路径（如取 $y = kx$ 让结果含参数 $k$、或 $y = x^2$）使极限值不同。
  • 连续：$f$ 在 $(x_0, y_0)$ 连续 $\iff \lim_{(x, y) \to (x_0, y_0)} f(x, y) = f(x_0, y_0)$ （要求该点有定义、极限存在且二者相等）。

2. 有界闭区域上连续函数的性质

  • $f \in C(D)$，$D$ 为有界闭区域（连通） $\implies$
  1. $f$ 有界，且在 $D$ 上取得最大、最小值（最值定理）
  2. $f$ 取得介于最大、最小值之间的一切值（介值定理）

说明与总结：

  • 前提：$D$ 必须有界且闭，$f$ 在 $D$ 上连续。
  • 介值定理还需 $D$ 连通（道路连通）——本处“区域”默认连通；若 $D$ 不连通介值结论不成立。
  • 最值定理是求多元最值题的理论基础（保证最值存在，只需比较内部驻点与边界）。
  • 注：一致连续（Cantor 定理）超出考研数学考纲，不要求掌握。

3. 偏导数定义

$$f_x(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}$$

说明与总结：

  • 对 $x$ 求偏导即把 $y$ 视为常数对 $x$ 求导；$f_y$ 同理。
  • 分段点/特殊点处必须用定义求。
  • 记号 $f_x = \frac{\partial f}{\partial x} = z_x$。
  • 多元函数某点偏导存在不保证函数在该点连续，也不保证可微（一元此结论才成立，多元失效）。

4. 全微分与可微的充要/充分条件

$$\mathrm{d}z = f_x ,\mathrm{d}x + f_y ,\mathrm{d}y$$

  • 可微定义：$\Delta z = f_x \Delta x + f_y \Delta y + o(\rho)$，$\rho = \sqrt{\Delta x^2 + \Delta y^2}$。
  • 必要条件：可微 $\implies$ 两个偏导存在 且 函数连续（但偏导未必连续）。
  • 充分条件：$f_x, f_y$ 在该点连续 $\implies$ 可微。
  • 极限验证：$\lim_{\rho \to 0} \frac{\Delta z - f_x \Delta x - f_y \Delta y}{\rho} = 0$。
  • 近似估值：$f(x_0 + \Delta x, y_0 + \Delta y) \approx f(x_0, y_0) + f_x \Delta x + f_y \Delta y$。

说明与总结：

  • 关系链：偏导连续 $\implies$ 可微 $\implies$ （偏导存在 且 函数连续），三个箭头逆均不成立。
  • 验可微（尤其驻点/分段点）用 $\lim_{\rho \to 0} \frac{\Delta z - f_x \Delta x - f_y \Delta y}{\rho} = 0$。
  • 估值直接用（数三高频）：$f(x_0 + \Delta x, y_0 + \Delta y) \approx f(x_0, y_0) + f_x \Delta x + f_y \Delta y$，即用切平面近似函数值，是全微分在近似计算/填空题中的主要落点。

5. 二阶混合偏导相等定理（含记号约定）

$$f_{xy}(x_0, y_0) = f_{yx}(x_0, y_0) \quad (\text{两混合偏导在该点连续})$$

说明与总结：

  • 条件：两个二阶混合偏导 $f_{xy}, f_{yx}$ 在点 $(x_0, y_0)$ 处连续，则二者相等（求导次序可交换）。
  • 记号约定（本讲义统一主流写法）：$f_{xy} = \frac{\partial^2 f}{\partial y \partial x}$ 表示先对 $x$ 后对 $y$——下标 $xy$ 自左向右读、$\partial$ 记号自右向左读，二者求导次序一致，对照真题不会绕晕。
  • 混合偏导连续时次序无关，记号差异不影响结果。实操中常配链式法则求二阶导。

6. 多元复合函数求导（链式法则）

$z = f(u, v), u = u(x, y), v = v(x, y)$：

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$

$$\frac{\partial z}{\partial y} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial y} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial y}$$

说明与总结：

  • “连线相乘、分线相加”。
  • 求二阶导时注意 $\frac{\partial z}{\partial u} = f_u(u, v)$ 仍是 $u, v$ 的复合函数，须再次链式求导（这是二阶导失分高发处）。
  • 一元中间变量（如 $u = u(t), v = v(t)$）时用 $\frac{\mathrm{d}z}{\mathrm{d}t} = \frac{\partial z}{\partial u}\frac{\mathrm{d}u}{\mathrm{d}t} + \frac{\partial z}{\partial v}\frac{\mathrm{d}v}{\mathrm{d}t}$（全导数）。

7. 一阶全微分形式不变性

$$\mathrm{d}z = \frac{\partial z}{\partial u} ,\mathrm{d}u + \frac{\partial z}{\partial v} ,\mathrm{d}v$$

说明与总结：

  • 无论 $u, v$ 是自变量还是中间变量，一阶全微分形式不变。
  • 配合微分法则 $\mathrm{d}(u \pm v) = \mathrm{d}u \pm \mathrm{d}v$、$\mathrm{d}(uv) = v,\mathrm{d}u + u,\mathrm{d}v$、$\mathrm{d}\left(\frac{u}{v}\right) = \frac{v,\mathrm{d}u - u,\mathrm{d}v}{v^2}$ 等，是求复合/隐函数全微分的利器，可避开链式法则的繁琐。

8. 隐函数求导（单方程，含二阶导思路）

$F(x, y, z) = 0$ 确定 $z = z(x, y)$：

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z} \quad (F_z \neq 0)$$

说明与总结：

  • 条件（隐函数存在定理）：$F$ 有连续偏导、$F(P_0) = 0$、$F_z(P_0) \neq 0$。
  • 一元 $F(x, y) = 0$（设 $F_y \neq 0$）时 $\frac{\mathrm{d}y}{\mathrm{d}x} = -\frac{F_x}{F_y}$。
  • 求二阶偏导（高频难点）：对已解出的 $\frac{\partial z}{\partial x}$ 再对 $x$（或 $y$）求偏导，凡出现 $z$ 处都要按 $z = z(x, y)$ 链式继续，最后把一阶结果代回。
  • 更稳的办法：对原方程两边求全微分，整理成 $\mathrm{d}z = (\cdots)\mathrm{d}x + (\cdots)\mathrm{d}y$ 后比系数读出各阶偏导。

9. 极值的必要条件与充分条件（二阶判别）

  • 驻点：$f_x = f_y = 0$
  • 设：$A = f_{xx}, B = f_{xy}, C = f_{yy}, \Delta = AC - B^2$
  • $\Delta > 0$：有极值（$A > 0$ 极小，$A < 0$ 极大）
  • $\Delta < 0$：非极值（鞍点）
  • $\Delta = 0$：判别失效，另议

说明与总结：

  • 必要条件：可偏导的极值点必为驻点（驻点不一定是极值点）。
  • 充分条件要求 $f$ 在该点的某邻域内有二阶连续偏导，且 $A, B, C$ 取驻点处的值。
  • 偏导不存在的点也可能是极值点（如 $z = \sqrt{x^2 + y^2}$ 在原点），须单独考察。

10. 条件极值与拉格朗日乘数法

$$\min / \max f(x, y) \quad \text{s.t.} \quad \varphi(x, y) = 0$$

构造拉格朗日函数：

$$L(x, y, \lambda) = f(x, y) + \lambda \varphi(x, y)$$

求驻点方程组：

$$\begin{cases} L_x = f_x + \lambda \varphi_x = 0 \ L_y = f_y + \lambda \varphi_y = 0 \ \varphi(x, y) = 0 \end{cases}$$

说明与总结：

  • 解方程组得驻点，再据实际问题比较定最值（通常实际问题最值存在，无需二阶判别）。
  • 多约束时引入多个乘子：$L = f + \lambda_1 \varphi_1 + \lambda_2 \varphi_2$。
  • 几何意义：相切处 $\nabla f = \lambda \nabla \varphi$（两梯度共线/平行）。

11. 有界闭区域上最大最小值求法

$$\max_D f = \max { f(\text{内部驻点/偏导不存在点}), f(\text{边界最值}) }$$

说明与总结：

  • 步骤：
  1. 求 $D$ 内部驻点及偏导不存在点处的函数值；
  2. 求 $f$ 在边界上的最值（化为一元或用拉格朗日）；
  3. 比较所有值取最大/最小。
  • 由最值定理保证最值一定存在（前提 $f \in C(D)$、$D$ 有界闭）。

12. 二重积分的概念与几何意义

$$\iint_D f(x, y) ,\mathrm{d}\sigma = \lim_{\lambda \to 0} \sum_{i=1}^n f(\xi_i, \eta_i) ,\Delta \sigma_i$$

说明与总结：

  • 几何意义：$f \geq 0$ 时为以 $D$ 为底、$z = f(x, y)$ 为顶的曲顶柱体体积；$f \equiv 1$ 时 $\iint_D \mathrm{d}\sigma =$ 区域 $D$ 的面积。
  • $\lambda$ 为各小区域直径的最大值。
  • 可积充分条件：$f$ 在有界闭区域 $D$ 上连续。（二重积分数一、数二、数三均要求；三重积分及曲线、曲面积分为数一专属。）

13. 二重积分的基本性质

  • 线性：$\iint_D (a f + b g) = a \iint_D f + b \iint_D g$
  • 可加：$\iint_{D_1 \cup D_2} f = \iint_{D_1} f + \iint_{D_2} f$
  • 保序：$f \leq g \implies \iint_D f \leq \iint_D g$
  • 估值：$m S \leq \iint_D f \leq M S$
  • 中值：$\iint_D f = f(\xi, \eta) S$

说明与总结：

  • $S$ 为 $D$ 的面积，$m, M$ 为 $f$ 在 $D$ 上的最小、最大值。
  • 可加性中 $D_1, D_2$ 无公共内点。
  • 中值定理要求 $f \in C(D)$、$D$ 为有界闭连通区域，$(\xi, \eta) \in D$。
  • 保序性常用于比较积分大小、估计积分范围。

14. 直角坐标下化二次积分

  • $X$ 型 $D$：$a \leq x \leq b, \varphi_1(x) \leq y \leq \varphi_2(x)$：

$$\iint_D f = \int_a^b \mathrm{d}x \int_{\varphi_1(x)}^{\varphi_2(x)} f(x, y) ,\mathrm{d}y$$

  • $Y$ 型 $D$：$c \leq y \leq d, \psi_1(y) \leq x \leq \psi_2(y)$：

$$\iint_D f = \int_c^d \mathrm{d}y \int_{\psi_1(y)}^{\psi_2(y)} f(x, y) ,\mathrm{d}x$$

说明与总结：

  • 据被积函数与区域形状选择积分次序。
  • 内层遇 $\int e^{-x^2} ,\mathrm{d}x$、$\int \frac{\sin x}{x} ,\mathrm{d}x$、$\int \frac{\mathrm{d}x}{\ln x}$ 等无法显式积出的原函数时，须交换积分次序。

15. 极坐标下二重积分

$$\iint_D f(x, y) ,\mathrm{d}\sigma = \int_\alpha^\beta \mathrm{d}\theta \int_{r_1(\theta)}^{r_2(\theta)} f(r \cos \theta, r \sin \theta) r ,\mathrm{d}r$$

说明与总结：

  • 令 $x = r \cos \theta, y = r \sin \theta$，面积元 $\mathrm{d}\sigma = r ,\mathrm{d}r ,\mathrm{d}\theta$（勿漏因子 $r$）。
  • 适用：区域为圆/扇形/环形，或被积含 $x^2 + y^2$、$\sqrt{x^2 + y^2}$。
  • 经典结论：$\int_{-\infty}^{+\infty} e^{-x^2} ,\mathrm{d}x = \sqrt{\pi}$（由 $\iint e^{-(x^2 + y^2)}$ 转极坐标得）。

16. 对称性与轮换对称性

  • $D$ 关于 $y$ 轴对称：

  • $f(-x, y) = -f(x, y) \implies \iint_D f = 0$

  • $f(-x, y) = f(x, y) \implies \iint_D f = 2 \iint_{D_{x \geq 0}} f$

  • $D$ 关于 $y = x$ 对称 $\implies \iint_D f(x, y) ,\mathrm{d}\sigma = \iint_D f(y, x) ,\mathrm{d}\sigma$

说明与总结：

  • 先看区域对称、再看被积函数关于对称变量的奇偶性（二者都满足才可用）。
  • 轮换对称（关于 $y = x$ 对称）可交换 $x, y$ 地位，常用于化简或证 $\iint_D x ,\mathrm{d}\sigma = \iint_D y ,\mathrm{d}\sigma$。
  • 能极大简化计算，务必优先检查。

17. 全微分的近似计算公式（数三高频）

$$f(x_0 + \Delta x, y_0 + \Delta y) \approx f(x_0, y_0) + f_x(x_0, y_0) \Delta x + f_y(x_0, y_0) \Delta y$$

说明与总结：

  • 由可微定义 $\Delta z = f_x \Delta x + f_y \Delta y + o(\rho)$ 略去高阶无穷小得（几何上即用切平面近似曲面）。
  • 用法：选取 $f$ 简单且 $(x_0, y_0)$ 取整、$\Delta x, \Delta y$ 小的基点，代入即得近似值。
  • 典型如估 $\sqrt{1.02^2 + 1.97^2}$、$1.04^{2.02}$ 等。这是该考点下小题/填空的主要出题方式。

18. 交换二重积分次序（独立操作范式）

$$\int_a^b \mathrm{d}x \int_{\varphi_1(x)}^{\varphi_2(x)} f ,\mathrm{d}y \xrightarrow{\text{画 } D \text{ 重定限}} \int_c^d \mathrm{d}y \int_{\psi_1(y)}^{\psi_2(y)} f ,\mathrm{d}x$$

说明与总结：

  • 范式三步：
  1. 由内外层上下限画出积分区域 $D$；
  2. 按目标次序（$X$ 型 $\leftrightarrow$ $Y$ 型）重新确定上下限，分块时按子区域分段写；
  3. 改写积分。
  • 典型触发：内层原函数积不出（$e^{-y^2}$、$\frac{\sin x}{x}$、$\frac{1}{\ln x}$）必须换序。
  • 示例：$\int_0^1 \mathrm{d}x \int_x^1 e^{-y^2} ,\mathrm{d}y = \int_0^1 \mathrm{d}y \int_0^y e^{-y^2} ,\mathrm{d}x = \int_0^1 y e^{-y^2} ,\mathrm{d}y = \frac{1}{2}(1 - e^{-1})$。

19. 二重积分的应用（面积/质量/形心/平均值）

  • 面积：$S = \iint_D \mathrm{d}\sigma$
  • 质量：$M = \iint_D \mu(x, y) ,\mathrm{d}\sigma \quad (\mu \text{ 为面密度})$
  • 形心：$\bar{x} = \frac{1}{S} \iint_D x ,\mathrm{d}\sigma, \quad \bar{y} = \frac{1}{S} \iint_D y ,\mathrm{d}\sigma$
  • 平均值：$\bar{f} = \frac{1}{S} \iint_D f ,\mathrm{d}\sigma$

说明与总结：

  • $f \equiv 1$ 求面积是最常见入口；薄片质量取 $\mu$ 为面密度。
  • 形心（密度均匀时与质心重合）、区域上函数平均值偶有出现，数三相对弱化但属应用题套路。
  • 计算时优先用对称性/轮换对称化简。

20. 偏导/连续/可微关系的经典反例速记

$$f(x, y) = \begin{cases} \frac{xy}{x^2 + y^2}, & (x, y) \neq (0, 0) \ 0, & (x, y) = (0, 0) \end{cases}$$

说明与总结：

  • 辨析题速记反例（均在原点考察）：
  1. 上式 $f$ 在原点两偏导存在（$f_x(0, 0) = f_y(0, 0) = 0$），但不连续（沿 $y = x$ 趋于 $\frac{1}{2}$、沿 $y = 0$ 趋于 $0$）——说明“偏导存在 $\nRightarrow$ 连续”。
  2. $g = \sqrt{x^2 + y^2}$ 在原点连续但两偏导不存在——说明“连续 $\nRightarrow$ 偏导存在”。
  3. 偏导存在且函数连续仍未必可微，需用极限式验证。
  • 配合关系链卡使用，应对“给条件判可微/连续”的选择题。
